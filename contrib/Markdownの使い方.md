# Markdownの使い方
- 最低限必要な情報のみをここで述べる
- より詳しく知りたい場合は[こちら](https://qiita.com/KodoCode/items/3b24fa8e87869cc73bfc)を参照するように
## 見出し
- 見出しは以下のように`#`を用いて表し、個数に応じて大きさが変わる
- 個数については3個までではなくより増やすこともできる
```
# 見出し1
## 見出し2
### 見出し3
```
# 見出し1
## 見出し2
### 見出し3

## 箇条書き・番号
- 箇条書きや番号を付けたい場合は以下のようにする
```
- 箇条書き
    - このようにすると細かく分類できる
1. 番号
    1. 番号も同じように反映される    
```
## アンダーライン
- このドキュメントでも使用されているような区切り線を書きたい場合は以下のように`---`を用いることでその部分に線を引くことができる
```
内容1
---
内容2
```
## 画像の挿入方法
- 画像についてはあらかじめ`image`フォルダに入れておくこと
- `alt text`の部分には画像が表示されない場合のテキストを入れる(基本このままでよい)
- `画像のパス`の部分には画像のファイル名が`test.png`であった場合には`image/test.png`を入れると良い
```
![alt text](画像のパス)
```
## リンクの挿入方法
- リンクは`表示テキスト`と`リンク先`を指定する必要がある
- このようにすることで表示テキストがリンクに変わる
```
[表示テキスト](リンク先)
```
## 文字の強調
- 文字を太字にしたい場合は`**`でそのテキストを囲むとよい
```md
**強調**
```
## 文字に下線を引く
- markdownでは下線を引く記法は存在しないが、以下のようにすることで下線を引くことができる
```md
<u>下線を引きたいテキスト</u>
```
