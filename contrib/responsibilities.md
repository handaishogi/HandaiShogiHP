# 仕事内容

## 部員紹介の更新

### 学年の更新
4月になったタイミングで学年の更新を行う．作業内容自体はシンプル．
```
<変更前>
## 1回生
<変更後>
## 2回生
```

### 新入生の追加（一番の仕事）
5月の確定新歓が終わったタイミングで`members.md`を更新する．部員名簿は部長が持っているので共有してもらう．

掲載する内容は以下の5点．
- 氏名
- 所属：学部学科（学部生の場合），研究科（院生の場合）
- 出身：都道府県だけでよい
- 師匠：誰かに弟子入りしている場合のみ，なければ不要
- 特徴：その人の性格など

### 卒業生の削除
2月～3月の追いコンのタイミングで卒業される先輩の名前を消しておく．卒業される先輩はグループで確認できる．
